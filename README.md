# Competitive Programming & Algorithmic Problem Solving

A structured archive of my solutions to algorithmic problems from **Codeforces** and **ICPC** training tracks (FcdsICPC / NCPC). Focused on writing clean, time- and space-optimized code in **C++** and **Java**.

## Profiles
* **Codeforces:** [Abdelrahman30](https://codeforces.com/profile/Abdelrahman30)

## Repository Structure
Solutions are categorized by core algorithmic paradigms and data structures:

* `/data-structures` — Trees, Segment Trees, Fenwick Trees, Disjoint Set Union (DSU), Stacks/Queues
* `/dynamic-programming` — 1D/2D DP, Knapsack, LIS, Bitmask DP
* `/graphs` — BFS, DFS, Dijkstra, Shortest Paths, Minimum Spanning Tree (MST), Topological Sort
* `/greedy-and-sorting` — Interval scheduling, Two Pointers, Sliding Window
* `/binary-search` — Standard binary search, Binary Search on Answer
* `/math-and-number-theory` — Prime sieves, Modular arithmetic, GCD/LCM, Combinatorics

## Tech Stack
* **Language:** C++
* **Focus Areas:** Time/Space Complexity Analysis, Edge-Case Handling, Algorithmic Optimization
